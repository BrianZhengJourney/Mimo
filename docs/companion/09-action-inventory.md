# 9. 动作清单(Action Inventory)

**状态：长期内容 inventory；P1 Starter Actions 的代码契约已实现（2026-07-28）。**
本节的 ~190 帧仍是扩展上限，不是首次领养门槛。当前 App 内激活包是

## 9.0 本节拍板的决策

| | 决策 | 依据 |
|---|---|---|
| **D9** | 签名动作**按气质共享 6 套**(gentle-cozy / quiet-curious / bright-playful / brave-loyal / dreamy-mysterious / odd-whimsical,与 `custom_pet.swift` 的 `CustomPetTemperaments` 一一对应)。共享的是**动作设计 + prompt + 行为包**;图仍按每只伴灵用自己的形象生成 | 同样的帧 + 不同权重 = 不同性格(§handoff 洞察);新增气质的边际设计成本为零 |
| **D10** | **Mimo 状态集要做**(得意/萎靡/困倦/深工),这是相对普通桌宠的核心差异化 | 用户确认 |
| **D11-R1** | Tennis 图中不画球；runtime 合成一个确定性球。其他复杂道具仍按动作逐项决定 | 已实现的单球轨迹不会跨帧漂移、复制或消失；比让模型重复画球更稳定 |

## 9.4 过渡帧与打断语义

**过渡帧决定质感**(§handoff 洞察)。清单里已显式计入的过渡:
坐下 4 · 起身 3 · 入睡 2 · 落地 4 · 各签名动作的起手/收尾。
行为包用链表达:`Stand → SitDown → SitIdle`、`Juggle起手 → Juggle循环 → Juggle收球`。

**打断语义**:
- 通用打断 = 反应层"被打断 5"(从惊讶姿势起);
- **带道具的动作被打断时,先播该动作自己的收尾 1 帧再进"被打断"**
  (链已支持),避免道具在两帧之间凭空消失的"啪"感;
- v2(独立道具 sprite)才能做"球滚走、伴灵去追"——记入 §9.8,不阻塞 v1。

## 9.5 图表打包规则

- 每张 **4×4 @2048²**(16 格,每格恰好 512px = 输出尺寸);
- **画布必须被行列数整除** —— 切分器的硬约束。3×3@2048 就是死在这里
  (2048÷3=682.67,"682px 的格子"从未存在过),2026-07-21 已修;
- **一个动作不跨张**(单张内部一次前向传播,一致性最强;留空格没关系),
  推论:单动作 ≤16 帧;
- 同张尽量装姿态相近的动作(站姿归站姿、坐姿归坐姿),给共享基线让路;
- 每格与**同阶段基准**过一致性闸门:pass 9.0 / fail 13.0(已标定,勿改回直觉值)。
  注意:走路帧是 3/4 侧面视角,而基准立绘是正面 —— 阈值可能需要为侧身帧重标定,
  首验时 DEBUG 构建保留全部尝试,正好用来核这个;
- 自动重掷上限 3 次(`ActionSheetRunPolicy`,已实现)。

## 9.6 首验计划:走路 16 帧(~$0.05)

1. 生成 S1 = **走路 16 帧整张**(两步 × 8 相位,第 16 帧回接第 1 帧;
   3/4 侧面、面向左,运行时镜像出向右)—— 生产打包即验证打包;
2. 闸门:每格 vs 基础立绘(同阶段)pass 9.0 / fail 13.0,侧身帧若普遍偏高则重标定;
3. 肉眼验收:① 跨帧身份一致 ② 脚底锚点推导稳定(不上下跳)
   ③ app 里循环顺滑、不滑步 ④ 绿幕抠图边缘干净;
4. 16 帧如果反而不顺(相位被模型画乱),退回 8 帧关键相位版对比;
5. 走路通过后按层批量:通用层 → 状态集 → 用户当前伴灵的气质签名集。
